# SILENCE: a WH-1000XM6 fan concept

A landing page made of noise that goes silent when you put the headphones on. Built by Web Atelier as an unofficial fan concept, not affiliated with or endorsed by Sony. Product and scene images are AI-generated illustrations.

- `site/`: static page (Matter.js, Lenis from CDN), served by nginx (`Dockerfile`, `nginx.conf`, `/healthz`).
- Live: https://silence.yan.io.vn (noindex).
- Source of truth for edits: `video-plans/web-atelier/sony/site`, copied here before each deploy.
